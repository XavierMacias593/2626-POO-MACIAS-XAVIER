# restaurante_app - Semana 11

Aplicación de consola para administrar productos y usuarios, registrar ventas y controlar stock.

## Ejecución

Desde esta carpeta:

```bash
python main.py
```

Los datos se guardan en `datos/productos.json`, `datos/usuarios.json` y `datos/ventas.json`. La explicación completa de la estructura, responsabilidades, persistencia, excepciones y pruebas está en el [`README.md`](../README.md) de Semana 11.
